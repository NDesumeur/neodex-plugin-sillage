# Sillage

Un jeu de rythme en vol : ton vaisseau file sur quatre altitudes au-dessus d'une ville de nuit. Cueille les étoiles en rythme et passe les portes d'énergie au turbo.

Les 200 morceaux de Rythme, ou une musique de NeoMusic analysée par le jeu. Monte et descends pour cueillir les étoiles, reste sur les rubans, frappe le turbo aux portes. Plein écran, difficulté calculée en étoiles, note de S à D.

Ses données (records, réglages) sont rangées dans le dossier du plugin, que NeoDex sauvegarde (synchro cloud comprise).

## Installer

Dans NeoDex : **NeoStore → À découvrir → Sillage → Installer**.

Développer un plugin : voir le [SDK NeoDex](https://github.com/NDesumeur/neodex-sdk).
